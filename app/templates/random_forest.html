Random Forest

À propos du modèle

Random Forest est un ensemble d’arbres de décision construits sur des sous-échantillons des données. Chaque arbre vote pour la prédiction finale. Ce modèle est robuste face au surapprentissage et gère bien les variables catégorielles.

Analyse

Le modèle Random Forest atteint un score moyen de 80.79%. Il est précis pour les cas légers, mais détecte moins bien les cas graves.

  • Précision : 85 % pour les cas légers, faible taux de faux positifs.
  • Détection des cas graves : Recall de 23.8 % (4 657 accidents graves correctement identifiés).
  • F1-score : 0.34, compromis entre précision et rappel.

Conclusion : Modèle robuste et stable, moins performant que le Gradient Boosting pour les cas graves, mais efficace pour la détection globale. Comme pour tous les modèles, les cas graves restent difficiles à identifier.
