Gradient Boosting

À propos du Gradient Boosting

Le Gradient Boosting est un algorithme d'ensemble qui combine plusieurs arbres de décision faibles pour créer un modèle puissant. Chaque nouvel arbre corrige les erreurs des précédents, ce qui permet d’améliorer la précision globale. Il est particulièrement efficace pour la classification et la régression sur des données structurées.

Analyse

Le modèle Gradient Boosting est un algorithme puissant basé sur l'assemblage d'arbres de décision. Il atteint un score moyen de 80.94 %, avec une bonne précision globale, mais détecte moins bien les cas graves.

  • Précision : 86 % pour les cas légers, peu de faux positifs.
  • Détection des cas graves : Recall de 31 % (6 125 accidents graves correctement identifiés).
  • F1-score : 0.40, compromis entre précision et rappel.

Conclusion : C’est actuellement le meilleur modèle de vos tests, combinant performance globale et stabilité. Comme pour tous les modèles, les cas graves restent plus difficiles à détecter, mais il reste le plus efficace pour nos données.
